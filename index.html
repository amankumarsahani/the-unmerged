The Unmerged

A repository is read as a record of what got built. It is equally a record of what didn't — the pull request that went quiet, the branch nobody deleted, the commit that was taken back. That half never gets read. Name a repository and it will speak.

What just happened

The history came from the GitHub REST API. Every line written underneath it came from SmolLM2-135M-Instruct — Apache-2.0 open weights that downloaded into this tab and generated on your own hardware. There is no inference server, no API key, and no account. Nothing about the repository you typed left this device, because there is nowhere for it to go.
