Git Séance

Every repository is a graveyard. Reverted commits, erased files, pull requests that died waiting for review — all of it is still in the history, and none of it gets a funeral. Name a repository and the dead will speak.

What just happened

The repository's history came from the GitHub REST API. Everything after that — every epitaph on this page — was written by SmolLM2-360M-Instruct, an Apache-2.0 open-weight model that downloaded into this browser tab and generated on your own hardware. No inference server. No API key. Nothing about the repository you searched left this device.

Open weights, open data, open source — source · model · built for Hacktoberfest 2026
